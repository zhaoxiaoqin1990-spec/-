一、整体计算思路

1.1 系统构成

缆索吊系统由以下构件组成，程序对每类构件分别进行受力计算：

构件作用验算内容
主索（承载索）nc 根并排，承受全部垂向荷载K₁≥3.0；K₂≥2.0
起重索（提升索）通过滑轮组提升重物K₁≥5.0

甲端塔架（低端）支撑主索甲端，承受斜拉力K₀₁≥1.3；Kc≥1.3
乙端塔架（高端）支撑主索乙端，承受较大斜拉力K₀₁≥1.3；Kc≥1.3
风缆索抵抗塔架倾覆弯矩张力 T_F（由力矩平衡求出）

二、模块一：设计模块

📐
设计模块（自动选型）
依据：周继祖《缆索吊车》第4章、第5章

功能：根据跨度、吊重等基本参数，从数据库中自动挑选满足安全系数要求的主索、起重索、牵引索型号，并给出塔架建议高度。

2.1 主索计算

（1）荷载计算

Q设计 = Q × (1 + φ) + G_吊钩 [kg] Q_单 = Q设计 / nc [kg，每根主索承担集中力] q = w_绳 + q_附加 / nc [kg/m，每根线荷载，w_绳为单位自重]

冲击系数 φ 通常取 0.25，G_吊钩默认取 Q×0.05（可在高级选项中修改）。

（2）水平张力 H（抛物线理论）

H = q·L² / (8f) + Q_单·L / (4f) [kg]

第一项为均布荷载引起的水平分力，第二项为跨中集中荷载（荷载在跨中时水平力最大，此处取控制工况）。

（3）两端竖向分力

V_A = q·L/2 + Q_单/2 − H·h/L [甲端，低端] V_B = q·L/2 + Q_单/2 + H·h/L [乙端，高端]

高差 h 使乙端竖向分力增大，甲端减小。当 h=0 时 V_A = V_B。

（4）最大张力（控制值）

T_max = √(H² + V_B²) [乙端，即高端张力最大] φ_A = arctan(V_A / H) [甲端索端角] φ_B = arctan(V_B / H) [乙端索端角]

（5）安全系数验算

K₁ = T_p / T_max ≥ 3.0 [破断拉力 / 最大张力] σ_t = T_max / F_K [拉伸应力，kg/mm²] σ_w = (Q_单/2) · √(E_K / (T_max·F_K))[弯曲应力（绳绕滑轮引起）] σ_z = σ_t + σ_w [总应力] K₂ = σ'_b / σ_z ≥ 2.0 [折减强度极限 / 总应力]

（6）索长估算

弦长 S₀ = √(L² + h²) 索长 S ≈ S₀ · (1 + 8f² / (3·S₀²)) [抛物线弧长近似公式，含15m余量]
2.2 起重索计算（滑轮组）
T_q = Q设计 / Σ(1/f_p^i)， i = 0, 1, …, n−1 f_p = 1.04（单滑轮阻力系数） K₁ = T_p / T_q ≥ 5.0 σ_z = T_q/F_K + E_K·d_s/D_滑轮 [含绕滑轮弯曲应力]

走绳段数 n 的含义

公式中的 n 是起重索穿过滑轮组后，同时承受吊重的绳段数（又称走绳数、倍率）。起重索从卷扬机引出，在定滑轮（固定于吊架）和动滑轮（随吊钩移动）之间来回穿绕——绕几段，就有几段绳共同承担荷载。

n 越大 → 每段绳受力越小 → 可选用更细的起重索；但滑轮数量增多，效率损失也随之增大（每经过一个滑轮，摩擦损失约 4%，即 f_p = 1.04）。

图示：蓝色框为定滑轮组（固定），绿色框为动滑轮组（随吊钩移动），橙色线为承力绳段

程序自动试算 n = 2, 4, 6, 8, 10，从最小绳径开始遍历数据库，找出首个满足 K₁ ≥ 5.0 的方案。

术语说明：程序界面中的"跑马绳数"即指此处的走绳段数 n。注意，"跑马绳"在不同语境下也指牵引绳（循环索），两者容易混淆，理解时以走绳段数为准。

2.3 牵引索计算（四步法）

第一步：最大升角 γ

tg γ = h/L + (L − 2l_a)/(2H) · (q + Q_单/L)

l_a 为牵引绳在甲端地锚处的水平距离（高级参数，默认 L/4）。

第二步：牵引索初张力 t₀

t₀ = q_牵 · l_a² / (8f_a)， f_a = 0.01·l_a

q_牵 为牵引索自重线荷载。

第三步：运行阻力

坡度阻力：w₁ = 2·Q_单·sin γ 摩擦阻力：f_m = μ₁·ρ/R + μ₀/R w₂ = 2·f_m·Q_单·cos γ

μ₁ 为钢轮滚动摩擦系数（≈0.06），μ₀ 为轴颈静摩擦系数（≈1.5），ρ 为车轮半径，R 为轴颈半径。

第四步：导向滑轮阻力 w₃

w₃ = (t₀ + w₁ + w₂) · (f_p^(a+b) − 1) t_max = t₀ + w₁ + w₂ + w₃ K₁ = T_p / t_max ≥ 4.0

a, b 为绳端和固定端的滑轮数（高级参数）。

2.4 塔架建议高度
净空高度要求：top_R = 障碍物高程 + 安全净空 + f 甲端塔高 ≥ max(5, top_R − 甲端地面高程) 乙端塔高 ≥ max(5, top_R + h − 乙端地面高程)
2.5 自动选型逻辑
1
过滤数据库：主索选 用途="主索" 的型号
2
依次试算 nc = 2, 4, 6, 8（若未固定）
3
对每个 nc，按绳径从小到大遍历主索型号，找第一个 K₁≥K₁要求 且 K₂≥2.0 的组合
4
起重索：试算走绳段数 n = 2, 4, 6, 8, 10（即 2段/4段…绳共同承力，详见 2.2节图示），遍历全部绳型，取首个满足 K₁ ≥ K₁要求 的方案
5
牵引索：基于已选主索的 H、q、Q，遍历绳型，找满足 K₁≥K₁要求 的最小型号

三、模块二：验算模块

✅
验算模块（既有方案复核）
依据：周继祖《缆索吊车》第4、5章

功能：已知缆索具体型号和参数，求满足全部安全系数要求的最大允许吊重 Q_max。

3.1 计算方法（二分法）

验算模块采用二分搜索求解 Q_max：

1
设定搜索区间 [0, 2000t]
2
取中值 Q_试，用与设计模块完全相同的公式计算 K₁(主索)、K₁(起重索)、K₁(牵引索)
3
若所有 K₁ 均满足要求，则 Q_试 可行，下界上移；否则 Q_试 不可行，上界下移
4
迭代 50 次，精度达到 0.001kg 级，下界即为 Q_max

最终按 Q_max 重新计算一遍所有安全系数，输出完整验算结论。

3.2 与设计模块的区别
设计模块验算模块
已知Q（吊重）缆索型号 + 参数
求解缆索型号最大允许吊重 Q_max
方法遍历数据库，找首个满足的型号二分法，精确求解临界荷载
用途新设计既有设备安全复核

四、模块三：塔架验算模块

🏗
塔架验算模块
依据：周继祖《缆索吊车》第6章

功能：验算甲、乙两端塔架的抗倾覆和抗滑移稳定性，计算所需风缆索张力。甲乙两端独立计算，逻辑相同。

4.1 作用在塔顶的力（主索 + 绳系合力）
竖向力 V_I = nc · T_max · (sin φ_B + sin α) / 1000 [t] 水平力 H_I = nc · T_max · (cos φ_B − cos α) / 1000 [t]

φ_B 为主索乙端升角，α 为主索甲端（或引索）升角。
起重索 + 牵引索 + 初张力合力：

T_绳合 = t_max + t₀ + T_q 竖向：v_rope = T_绳合 · sin φ_B / 1000 水平：h_rope = T_绳合 · cos φ_B / 1000
4.2 工况一：主索满载（荷载在跨中）
ΣV = V_I + v_rope + W₁ + W₂ [t，竖向合力] ΣH = H_I + h_rope + P_wind [t，水平合力] P_wind = 1.4 × 1.4 × w₀ × F_受风面积 / 1000 [t，风压标准值×双风压系数] M_风 = P_wind × H_t / 2 [t·m，风荷载绕底铰力矩] M_稳定 = ΣV × B/2 [t·m，重力稳定力矩] M_倾覆 = H_I·H_t + h_rope·H_t + M_风 [t·m，倾覆力矩] K₀₁ = M_稳定 / M_倾覆 ≥ 1.3 Kc = f · ΣV / ΣH ≥ 1.3 [f = 0.25，塔脚摩擦系数]

W₁ 为塔架自重，W₂ 为配重。

4.3 工况二：空索（无吊重）
V_II = 2·V_I， H_II = 2·H_I [空索时，主索两侧对称，力翻倍] ΣV_II = V_II + v_rope_II + W₁ + W₂ ΣH_II = H_II + h_rope_II [无风载工况] K₀₁_II = (ΣV_II·B/2) / (H_II·H_t + h_rope_II·H_t) ≥ 1.3 Kc_II = f·ΣV_II / ΣH_II ≥ 1.3
4.4 风缆索张力 T_F（力矩平衡法）

当工况一不满足 K₀₁ 要求时，需设风缆索。由绕塔底力矩平衡求所需风缆索张力：

T_F · (V_F · X_VF + H_F · y_VF) × 2 = K要求 · M_倾覆 − M_稳定 + W₂·B/2 V_F = sin(ψ)·cos(ξ) [风缆索竖向分量系数] H_F = cos(ψ)·cos(ξ) [风缆索水平分量系数] ψ = 风缆索与水平面夹角（俯仰角） ξ = 风缆索平面外偏角 X_VF = 风缆索在塔顶的水平作用点距底铰距离 y_VF = 风缆索竖向分力对底铰的力臂

T_F 即为每根风缆索所需最小张力，除以风缆索根数得每根张力，再按安全系数 K_F 核验选用型号。

五、模块四：沿线受力分析

📊
沿线受力分析
依据：周继祖《缆索吊车》第7章（升角概念）

功能：计算重物在不同水平位置 x 处，主索两端张力、主索端部升角、以及重物两侧主索升角（仰斜角）随位置的变化规律，以图表形式输出。

5.1 基本假设
  • 主索按抛物线理论计算（垂度适中，f/L ≤ 1/8 时误差很小）
  • 水平张力 H 沿索全长不变（抛物线索假设）
  • 集中荷载 Q 仅引起荷载点处额外下挠，不改变 H
  • 以甲端（A端）挂点为坐标原点，x 轴水平向乙端，y 轴向上
5.2 各位置受力公式

（1）每根主索承担荷载

Q设计 = Q × (1 + φ) [kg，总设计荷载] Q_单 = Q设计 / nc [kg，每根主索] q_单 = q_附加 / nc [kg/m，每根均布] H = q_单 · L² / (8f) [kg，水平张力，与位置无关]

（2）两端竖向分力（随位置 x 变化）

tan φ_A0 = (4f − h) / L [无荷载时甲端切线角正切] tan φ_B0 = (4f + h) / L [无荷载时乙端切线角正切] V_A(x) = H · tan φ_A0 + Q_单 · (L−x) / L [甲端竖向分力] V_B(x) = H · tan φ_B0 + Q_单 · x / L [乙端竖向分力]

当荷载靠近乙端（x→L），乙端竖向力增大；反之亦然。

（3）全部主索合计张力

T_A(x) = nc · √(H² + V_A²) / 1000 [t] T_B(x) = nc · √(H² + V_B²) / 1000 [t]

（4）主索端部升角

φ_A(x) = arctan(V_A / H) [甲端主索与水平夹角，°] φ_B(x) = arctan(V_B / H) [乙端主索与水平夹角，°]

（5）荷载点高度（空索 + 荷载挠度）

y₀(x) = h·x/L − 4f·(x/L)·(1−x/L) [空索时荷载点高度，甲端为零点，向下为负] δ(x) = Q_单·x·(L−x) / (H·L) [集中荷载引起的附加下挠] y_l(x) = y₀(x) − δ(x) [荷载点实际高度]

（6）重物两侧升角（仰斜角）

升角（仰斜角）指重物两侧主索与水平方向的夹角，决定主索对重物的合力方向。

α_L(x) = arctan(−y_l / x) [左侧升角：荷载点到甲端挂点（0,0）的弦线角度] α_R(x) = arctan((h − y_l) / (L−x)) [右侧升角：荷载点到乙端挂点（L,h）的弦线角度]

升角越大，起吊时绳索对重物的水平分力越大，同时小车爬坡阻力越大。

曲线左轴/右轴含义

六、注意事项

6.1 计算假设与适用条件
  • 抛物线假设：本程序采用抛物线近似（而非悬链线），适用于 f/L ≤ 1/10 的场合；垂度比较大时应按悬链线精确计算。
  • 集中荷载位置：设计模块将集中荷载置于跨中（产生最大水平张力的控制工况），并非实际最危险位置（最大张力可能出现在荷载位于高端附近）。沿线分析模块可查看全跨张力分布。
  • 主索并行：各根主索承担相同荷载（均等分配），实际安装中需保证各主索张力均匀。
  • 弯曲应力：σ_w 公式基于绳绕滑轮的等效弯曲应力近似，计算中滑轮直径 D 取高级参数输入值，务必与实际选用滑轮匹配。
6.2 安全系数标准
构件K₁（破断安全系数）K₂（强度安全系数）备注

6.3 数据库使用注意
  • 数据库分为主索型号（6×19 类，σ_b′=144.5 kg/mm²）和起重/牵引型号（σ_b′=125 kg/mm²），程序按 用途 字段筛选，请勿混用。
  • T_p（破断拉力）需由实测或厂家提供，程序内默认值仅供参考，正式工程必须以实际检测值为准。
  • 数据库中 d_s（钢丝直径）用于弯曲应力计算，应与实际绳型一致；修改数据库后须重新运行计算。
  • 新增或修改绳型后，下拉列表自动更新，已保存的设计结果不自动重算，需手动点击【▶ 计算】。
6.4 塔架计算注意
  • 程序仅验算塔架整体稳定（倾覆、滑移），不含塔身构件强度、焊缝、底脚螺栓等细部计算，需另行专项设计。
  • 风压 w₀ 应按工程所在地基本风压及高度系数确定，默认 50 kg/m² 为参考值。
  • 风缆索张力 T_F 为力矩平衡所需最小值，实际预张力应适当放大并考虑弹性变形。
  • 工况一（满载+风）和工况二（空载无风）均需验算，以较不利者控制。
  • 点击【→ 填入塔架验算】可将设计模块结果（T_max、φ_A/φ_B、塔高建议值）直接传入塔架模块，减少手动输入错误。
6.5 计算书导出注意
  • 导出格式为 .doc（HTML 伪 Word），可用 Microsoft Word 或 WPS 打开并二次编辑。
  • 导出前必须先执行计算，否则提示错误。
  • 计算书中包含所有中间结果和公式出处，但不含图纸；立面图和平面图需截图附入。
  • 本程序为辅助工具，导出计算书须经有资质的专业工程师审核签字方可作为正式文件使用。
